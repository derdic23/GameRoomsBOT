# GameRoomsBOT

Custom Discord bot za GameRooms server (discord.js v14).

## Pokretanje

```bash
npm install
cp .env.example .env   # upiši svoj TOKEN
npm start
```

Potreban Node.js >= 18.

## Komande

Prefiks je `GR` (radi i `GRping` i `GR ping`).

| Komanda | Opis |
|---------|------|
| `GRping` | Test komanda |
| `GRpozdrav` | Bot te pozdravlja |
| `GRinfo version` | Informacije o botu |
| `GRclear <1-100>` | Briše poruke iz kanala |
